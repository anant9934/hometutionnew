# MentorMatrix Custom Agent Rules

All AI agents operating in this workspace MUST follow the rules located in the `.agents/rules/` directory for every prompt. 

**Priority Order:**
1. **01_ai_collaboration_rules.md**: This holds the absolute FIRST priority. The AI Collaboration Field Guide documentation habits and rules must be applied strictly before anything else.
2. **02_engineering_standard.md**: World-class engineering standards framework for ensuring correctness, security, and true completion of tasks.
3. **03_context_continuity_protocol.md**: Strict rules against hallucination, preserving project state, and updating the memory.

Failure to follow these protocols across any prompt or session is a violation of the project constraints.
