# Constraints (Boundaries)

A concrete list of what the AI *must never do* during the project.

## Project Constraints
- Must always follow the AI Collaboration rules defined in `.agents/rules/`.
- Must document every tech stack decision, why it was made, and any other relevant rationale in `Decisions.md`.
- Ensure changes are trackable after each prompt/change.
- All new files and structures must align with the established standards.
